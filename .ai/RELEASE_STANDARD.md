# Release Standard

## Release Readiness

Before release:

* tests pass
* docs reflect current behavior
* changelog is updated
* no secrets are present
* database changes are documented
* API changes are documented
* investment outputs include the risk disclaimer

## Version Notes

Release notes should include:

* version
* date
* major changes
* migration notes
* known risks
* testing summary

## Deployment Boundary

OpenStock AI release notes must clearly distinguish:

* implemented
* tested
* usable
* planned
* blocked

Do not describe planned features as released.
