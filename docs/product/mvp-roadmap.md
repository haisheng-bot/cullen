# 第一阶段 MVP 路线图 v0.1

## 1. MVP 范围

第一阶段只做：

* 股票代码查询
* 美股基础数据
* SEC 财报读取
* AI 财报总结
* 新闻摘要
* 股票评分
* 研究报告生成
* 本地数据库保存

## 2. 暂不做

* 自动交易
* 实盘下单
* 期权策略
* 杠杆交易
* 高频交易

## 3. 里程碑

### M0 项目重建

* 标准文档
* 需求分析
* 架构设计
* GitHub 协作配置
* 基础测试

### M1 后端基础

* FastAPI 初始化
* 配置管理
* 数据库连接
* audit_logs 表

### M2 数据源

* yfinance
* SEC EDGAR
* FRED

### M3 AI 分析

* 模型统一接口
* SEC Filing Agent
* News Agent
* Report Agent

### M4 评分与报告

* Scoring Agent
* 评分模型
* 研究报告生成
