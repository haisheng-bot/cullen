# OpenStock AI 个人股票研究生产力目标 v0.1

## 1. 目标定位

OpenStock AI 首先要逐步进化成 Cullen 的个人股票研究生产力工具，为日常美股研究、组合跟踪、策略验证和报告沉淀提供技术支持。

它不是普通行情软件，不是交易终端，也不是自动下单系统。它的第一目标是帮助用户更快、更稳定、更可复盘地完成投资研究工作。

本系统仅用于投资研究辅助，不构成任何投资建议。

## 2. 产品原则

OpenStock AI 的开发优先级应服务以下原则：

* 先服务真实日常研究流程，再追求平台化扩展。
* 先让 Cullen 每天可以用起来，再逐步开放为通用平台。
* 先沉淀可追溯的数据、报告和决策过程，再增加复杂策略。
* AI 输出必须解释原因、风险和数据来源，不替用户做最终决策。
* Portfolio、回测、报告和复盘记录必须可以长期积累。

## 3. 每日研究主流程

```text
每日股票池扫描
  -> 候选股排序
  -> 单股深度研究
  -> Portfolio 跟踪
  -> 策略回测
  -> AI 解释
  -> 研究报告归档
  -> 次日复盘
```

## 4. 核心生产力场景

### 4.1 今日候选股票

系统每天扫描美股候选池，并输出值得进一步研究的股票列表。

第一阶段候选池包括：

* Most Active Top 100
* AI / Cloud
* Semiconductors
* Momentum
* Growth
* Energy
* Defense
* Crypto / Fintech

输出必须包括：

* 股票代码
* 公司名称
* 主题或行业
* 当前价格和涨跌幅
* 成交量和相对成交量
* AI / Algorithm 评分
* 推荐等级
* 主要理由
* 主要风险
* 数据来源

### 4.2 我的研究组合

系统应支持多个个人研究组合，例如：

* AI Portfolio
* Short-term Watchlist
* Long-term Watchlist
* Risk Hedge
* Earnings Watch

每个组合应支持：

* 添加股票
* 删除股票
* 查看组合权重
* 查看组合表现
* 查看组合风险
* 运行组合回测
* 生成组合报告

### 4.3 单股技术支持

系统应为单只股票提供研究支持：

* 实时价格
* K 线图
* 成交量和成交额
* 技术指标
* 财务指标
* SEC 披露
* 新闻和政策线索
* AI 评分
* 风险提示
* 可归档研究结论

### 4.4 策略测试与回测

系统应帮助用户验证组合和策略，而不是直接给出交易命令。

应支持：

* 策略选择
* 约束配置
* 历史回测
* 收益风险指标
* 最大回撤
* Alpha / Beta
* 贡献股票
* 风险解释
* 下一步复核建议

### 4.5 每日研究报告

系统应能生成每日研究报告，至少包含：

* 今日市场和候选池摘要
* 重点关注股票
* Portfolio 变化
* 新闻和 SEC 披露摘要
* 策略回测结果
* 风险提示
* 明日复盘事项

报告格式应逐步支持：

* Dashboard
* Markdown
* HTML
* PDF

## 5. 数据沉淀要求

为了成为生产力工具，系统必须沉淀历史记录：

* 每日候选池扫描记录
* 每只股票评分历史
* Portfolio 成员变化
* 回测结果
* AI 报告
* 研究结论
* audit_logs

这些记录用于回答：

* 这只股票以前为什么被关注？
* 上次 AI 是怎么判断的？
* 评分是上升还是下降？
* 组合风险是否变大？
* 回测结果是否稳定？
* 哪些结论后来被验证或推翻？

## 6. 阶段目标

### Phase A：日常可用

* 每日 Most Active Top 100 扫描
* 单股行情和推荐评分
* Portfolio 管理
* 基础回测
* 研究报告生成

### Phase B：可复盘

* 候选池历史
* 评分历史
* Portfolio 变更历史
* 报告归档
* 每日复盘入口

### Phase C：更智能

* News Agent
* Risk Agent
* Portfolio Agent
* Strategy Agent
* 自动生成每日研究报告

### Phase D：平台化

* Strategy Marketplace
* Agent Marketplace
* Workflow 模板
* Portfolio 模板
* 因子模型共享

## 7. 成功标准

短期成功标准：

* 用户每天可以打开工作台完成股票筛选。
* 用户可以维护自己的 Portfolio。
* 用户可以对组合运行回测。
* 用户可以生成一份可归档研究报告。

中期成功标准：

* 系统能展示历史评分变化。
* 系统能保存和对比历史报告。
* 系统能提示组合风险变化。
* 系统能形成每日研究闭环。

长期成功标准：

* OpenStock AI 成为用户日常美股研究的主工作台。
* 系统可以从个人生产力工具逐步演化为开放式 AI 投资研究平台。
