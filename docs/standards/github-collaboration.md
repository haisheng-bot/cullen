# GitHub 协作标准 v0.1

## 1. 仓库基础文件

项目必须包含：

* README.md
* LICENSE
* CONTRIBUTING.md
* SECURITY.md
* CHANGELOG.md
* .gitignore
* .env.example
* Pull Request 模板
* Issue 模板
* CI 工作流

## 2. Pull Request 要求

每个 PR 必须说明：

* 修改范围
* 测试结果
* 文档是否更新
* 是否涉及外部 API
* 是否涉及 AI 输出
* 是否涉及投资结论
